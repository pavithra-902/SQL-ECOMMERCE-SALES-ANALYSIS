# SQL E-Commerce Sales Analysis

## 📌 Project Overview

This project analyzes an **E-Commerce Sales Dataset using SQL**. It demonstrates fundamental SQL concepts and techniques used in **Data Analysis**.

## 🛠️ Skills Used

* `SELECT`
* `WHERE`
* `AND`
* `OR`
* `BETWEEN`
* `LIKE`
* `IN`
* `ORDER BY`
* `GROUP BY`
* `HAVING`
* **Aggregate Functions:** `SUM()`, `COUNT()`, `AVG()`, `MIN()`, `MAX()`
