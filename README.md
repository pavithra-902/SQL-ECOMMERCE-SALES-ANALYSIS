# SQL E-Commerce Sales Analysis

## Project Overview
This project analyzes an e-commerce sales dataset using SQL. It demonstrates fundamental SQL concepts used in data analysis.

## Skills Used
- SELECT
- WHERE
- AND
- OR
- BETWEEN
- LIKE
- IN
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions (SUM, COUNT, AVG, MIN, MAX)

## Tools
- MySQL Workbench
- GitHub

## Dataset
E-commerce Sales Dataset
